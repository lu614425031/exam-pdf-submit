# 紙本 Token 上機考交卷網站

## 啟動網站

教師電腦安裝 Python 3.10 以上，解壓縮後在該資料夾執行：

    py -3 -m pip install -r requirements.txt

單機試用執行 `py -3 server.py`。在教室使用時，由管理員確認有線區網連線與防火牆設定後，執行 `Start-Exam.cmd`。教師電腦開啟啟動視窗列出的完整 Teacher 網址，勿分享該網址。學生在自己的電腦以瀏覽器開啟 `http://教師機IPv4:8765/`。網站使用 HTTP，請讓管理員將存取限於考場網段。

## 考前準備

1. 在教師端貼上學號清單，每行一個學號，再按「登錄學號」。
2. 輸入需要的 Token 組數，按「產生 Token」，將清單複製保存並印到紙本題目卷。Token 產生時不指定學號，請限制清單存取。教師端會保存並顯示未使用的 Token，重新開啟時可查看或下載。資料庫包含可用的登入碼，請妥善保管。
3. 依考場座位與 A／B 卷配置發放題目卷。學號已登錄且 Token 尚未使用時，首次成功登入會將兩者綁定。短碼共八碼，中央連字號可省略。每個學號同時只能有一個登入。

## 考試與收卷

- 老師按「開放收件」。學生用自己的學號與紙本上的 Token 登入，依指定格式完成答案卷並匯出 PDF。
- 每人只收一份 PDF，最多 25 MiB。系統檢查檔案是可讀、未加密且至少有一頁的 PDF。答題內容和版型由老師批閱。
- 學生交卷成功後可下載浮水印 PDF 收件單。老師截止收件後下載 ZIP，裡面有每位學生的原始 PDF 答案卷與獨立收件單。
- Token 成功登入後立即失效。同一瀏覽器可重新整理，登入會保留。換機或登入失效時，由監考核對身分，在教師端重設該學號登入，再發給一組未使用的 Token。已使用的 Token 保持失效。若需更換已交的答案卷，教師可在該生的交卷紀錄旁按「退回重交」。收件開放時，學生重新整理後可再交一次，新檔成功送出才會取代舊檔。如果學生把學號和 Token 一起交給別人，對方可能搶先使用該組憑證登入。
- 資料保存在教師機 `one-time-exam.sqlite3`。重啟會保留既有資料並預設關閉收件。每場考試請使用新資料夾，或以 `--data 路徑` 使用新的資料庫。

正式考試前，請在借用的教室用兩台學生機試交，測試未登錄的學號和已使用的 Token 會被拒絕，以及截止後能匯出兩份原始答案卷。
